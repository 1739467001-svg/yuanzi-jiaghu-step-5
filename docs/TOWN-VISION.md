# 原子江湖 · 小镇重构思（v2 设计方案，待拍板）

> 本文是对「初始页面的建筑构思 / 星火亭替换 / 仿真度提升 / 桃花动效 / 高度与尺度」的系统提案。
> 结论先行：**建议把星火亭改成「群侠论剑台 · 英雄帖」**（A2A 平台最贴题的一块），
> 同时做三件事——水面与桥的拟真（含锦鲤、青蛙）、桃花源式的小镇氛围（飘瓣 + 桃园结义 + 时辰）、
> 整体建筑拔高 1.8—2.2 倍并把地图从 39×31 扩到 48×38。

问题很清楚：**高度压得死**（建筑只有 3—4 个单位高，相机一拉远就像积木）；**水面是死的**；

## 2. 六个建筑的重新构思

设计原则：**每栋建筑都要能回答「我在这里能干什么」**，且外形一眼可辨（剪影差异）。

| 建筑 | 现在 | 重做构思（外形 + 功能） |
| --- | --- | --- |
| 武林大会展示馆 | 大方盒 + 内厅展位 | **重檐歇山顶的两层展殿**，前置月台与旗杆，二层回廊挂满作品卷轴；月台就是真人作品的台阶，殿内展位抬高到二层视平。功能不变（38 条真实作品），但「走进大殿」的仪式感拉满。 |
| 江湖茶楼 | 方盒 + 上层阁 | **两层临水楼阁**，二层挑出观景台（正对小河与桃花岛），一层是茶桌共坐；加真人可坐的栏杆美人靠。功能不变（AI 私聊、茶桌共坐），新增「凭栏远眺」视角点。 |
| 共创工坊 | 方盒 + 烟囱 | **两层作坊 + 天井**，一层摆工作台/砧板/半成品原型，二层晾着布幡（共创中的作品）；烟囱随工坊里 AI 的活动冒火星粒子。功能不变（AI 共创对话）。 |
| 开源书院 | 方盒 | **三层书塔（塔式）**，层层出檐，内墙可见书架格与灯；塔前小院放共读石桌。承载「分享是最好的学习」与五条共建理念。 |
| **星火亭** | 4 柱小亭 | **见第 3 节：建议换成「群侠论剑台 · 英雄帖」** |
| 原子门派 | 两层殿 + 旗幡 | **门派广场**：殿前立各门派旗幡（数据驱动，本机/远程门派各一杆），殿前设聚义鼓；广场可容纳 12 名成员列席。功能不变。 |

另有两处新增「功能性场景」（可选，见第 5 节）：**桃林与桃园结义碑**（村口）、**河中桃花岛**（黄药师意象）。

## 3. 星火亭怎么办：三个方案

### 方案 A（推荐）：群侠论剑台 · 英雄帖
- **是什么**：一座环形石台（中央高台为论剑处，四周三级石阶看台），台边立「英雄帖」榜墙（一卷卷竹简/木牌，可翻页）。
- **A2A 落点**：这是全场景唯一能**看见 Agent 与 Agent 交互**的地方——AI 侠客定时到这里「论剑」（两两对立、三五成群），头顶浮出议题气泡（与茶楼私聊气泡同一套机制，但内容是公开的、可围观的）；你可以走到看台入座旁观，也可以「递帖」发起一个三方会谈（你 + 两位 AI 就某个议题聊）。
- **社区落点**：英雄帖榜墙展示社区悬赏与共创任务（后续可接原子公社的话题/活动数据，与门派网站同一个同步思路）。朝露、星河两位侠客的日程本就挂在这里，正好让他们做「论剑主持」。
- **外形**：圆形石台 + 环廊 + 兵器架 + 旌旗，剪影和方盒建筑完全不同，远处就能认出。

### 方案 B：星火驿 · 不灭火塘
保留「星火」的名：一座木栈营地，中央一团真正的火（粒子 + 夜间光源 + 火星上升），AI 侠客夜里围火而坐；这里是「星火计划」活动的聚集与公告处。优点：火效与夜景观感极佳、实现简单；缺点：A2A 属性弱于方案 A。

### 方案 C：百工集市
Social 集市：一排可逛的摊位（AI 摊主 + 真人寄卖），强调「个体至上、开放共享」。优点：热闹、可延伸成作品市集；缺点：与工坊/茶楼功能有重叠。

> 我推荐 A：它是唯一同时命中 **A2A 平台感 + 社区共建 + 金庸江湖**（论剑、英雄帖全是武侠母题）的方案，而且天然是「活的」——不需要额外内容运营，AI 的日常社交就会把它填满。

## 4. 拟真升级：水、桥、河里的生命

### 水面（最大提升点）
1. **真实平面反射**：用 Three 的 `Reflector` 做一张 256² 的反射贴图（桥上的人、柳树、桃花岛都会倒映在水里），只在桌面端开启，手机端降级为天空色渐变。
2. **波动**：反射层之上叠一层自定义 ShaderMaterial，用 3 组正弦/Gerstner 波让法线起伏，反射 UV 随之轻微扰动——水会「流」而不是「贴图滚」。
3. **细节**：岸边一圈泡沫（呼吸式透明度）、正午高光、夜间月影碎光；鱼跃出水时在水面荡开涟漪环（复用一组 ring 网格 + 扩散动画）。

### 桥
现在的桥是 12 段方箱。重做为：**拱券石桥**（楔形石块沿圆弧排布 + 桥心石）、栏杆（立柱 + 索链）、四个桥墩入水、桥面石板拼缝；倒影免费获得。桥宽放宽到 3.2（现在约 2.3），让人流与 AI 交汇时不显挤。

### 河里的生命（程序化，零素材）
| 角色 | 做法 | 数量 |
| --- | --- | --- |
| 锦鲤 | 扁平身体 + 双尾 + 背鳍，沿贝塞尔/环形路径巡游，偶尔加速、偶尔浮头吐泡 | 4—6 条（橙/白/墨三色） |
| 青蛙 | 蹲荷叶上的绿团子（身 + 双眼 + 后腿），定时起跳划过水面并溅起小水花，落回另一片荷叶 | 3 只 |
| 蝌蚪 | 小群黑点 + 摆尾，只在浅水区成群游动 | 12 条 |
| 蜻蜓 | 点水面点水，留下扩散涟漪 | 2 只 |
| 荷叶/鸢尾 | 河面点缀，青蛙的落点 | 8 片 |

以上全部是程序化几何 + 极简动画，无模型无贴图，移动端也扛得住。

## 5. 桃花主题与金庸灵感

### 5.1 天上飘落的花瓣（全局氛围，最划算的一个特效）
约 240 个 Points 粒子（一片花瓣 = 一个 6px 的抗锯齿面片），从桃树树冠高度生成，随风斜向下飘落，带左右摇摆与自旋；日景是浅粉、黄昏转橘、夜间被灯笼照成暖色。预算极低，一上就有「春天到了」的感觉。

### 5.2 桃园结义（场景级的高潮）
在村口（牌坊之后、正对广场）做一小片桃林：三棵桃树围一块青石碑（「桃园结义」），地面落瓣堆积、石上供一盏酒。
- **互动**：走到碑前 → 镜头缓缓推近、飘瓣加密、AI 侠客聚拢过来（如果附近有人），弹出一次性的结义对话（把社区的「个体至上、一群人能走更远」讲出来）。这是全小镇唯一的「事件型场景」，适合做新手引导的收尾高潮。

### 5.3 河中桃花岛（黄药师的桃花岛）
河中央扩出一座小岛：桃树 + 岩石 + 一张石琴台 + 一根竹笛（黄药师意象），刻「桃花岛」三字。岛与岸用一座九曲桥（Z 形小桥，不是直桥）相连——既是景观，也解决「桥只有两座且都一样」的单调。
- 氛围：岛上花瓣落得最密，白天有花瓣飘向河面，随水流向下游漂走。

### 5.4 桃花源（陶渊明）
把村口牌坊改成「桃林夹道」的入口：进村先穿过一段桃花小径（花瓣最浓 + 地面落瓣 + 石牌「桃花源」），出了小径豁然开朗见到小镇——这正是桃花源记的叙事，也天然解决了「一进游戏就是一堆房子、没有期待感」的问题。

### 5.5 环境与时辰（不做 24 小时下雨那种极端）
按时辰给氛围，而不是给天气灾难：
- **清晨**：河面薄雾（低空雾带 + 缓慢平移）、花瓣少、远处塔影；
- **正午**：水光最强、蝴蝶/蜻蜓活跃；
- **黄昏**：灯笼亮起、桃花转橘、火塘/工坊火星；
- **夜间**：月影碎波、流萤、AI 在论剑台围坐的火光。
- 雨天作为**稀有事件**（概率触发，5 分钟内结束），水面涟漪加密、AI 撑伞停走、屋檐滴水——不做常态。

## 7. 性能预算（手机优先）

| 效果 | 桌面 | 手机 |
| --- | --- | --- |
| 水面平面反射 | 256² Reflector | 关（用天空色 + 波动法线） |
| 花瓣粒子 | 240 | 120 |
| 锦鲤/青蛙/蝌蚪/蜻蜓 | 全开 | 减半 |
| 火塘/烟囱火星 | 开 | 开（数量减半） |
| 阴影 | 2048 | 1024 或关 |

按现在的实现方式（程序化几何 + Points），以上合计约 6—9 千个网格/2—4 万三角形，对中端手机仍在 60fps 量级；每加一项我都会用 `audit:mobile` 与 e2e 复核帧率手感。
