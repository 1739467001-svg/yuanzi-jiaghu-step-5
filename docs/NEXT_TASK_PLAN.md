# 原子江湖后续任务规划

目标：把当前可运行的 3D 展示原型，逐步变成可以持续添加地图、角色、赛事和 AI 能力的产品基础。每一步都先有可运行结果和验收条件，再进入下一步。

## 阶段 1：地图与内容基线（当前开始）

- 冻结地图坐标、入口、碰撞尺寸、建筑类型和占位状态。
- 把“功能待定建筑”作为正式配置类型，不能被误当成已上线功能。
- 为建筑和角色配置增加自动校验，避免新增配置破坏寻路或让角色前往不存在的地点。
- 验收：配置校验通过；所有建筑入口可达；占位建筑在 3D 场景和详情面板中都有明确标识。

## 阶段 2：展馆内容服务化

- 将赛事、届次、赛道、作品、媒体来源抽成稳定数据对象。
- 记录审核状态、来源位置、公开范围和版本号。
- 做一个只读展馆 API，让 3D 展厅、列表模式和 AI 导览读取同一份发布数据。
- 验收：新增一届赛事不修改场景代码；撤回作品后所有入口同时消失。

## 阶段 3：真实 3D 表现层

- 用批准后的 IP 参考制作 GLB 角色和建筑资产，替换当前几何占位模型。
- 固定镜头、动画、碰撞体、LOD 和低性能降级标准。
- 建立场景资源清单和授权记录。
- 验收：角色、建筑、遮挡、寻路和移动端性能达到 PRD 基准。

## 阶段 4：AI Town / Convex 接入

- 恢复并改造上游身份鉴权，不继续使用默认真人身份。
- 将上游公开位置映射到 Three.js；服务端成为位置和会话的最终依据。
- 私人聊天、公共活动和内容导览分别定义可见范围。
- 验收：两个浏览器账号可以移动、邀请、聊天、离开和重连，私人消息不会进入公共快照。

## 阶段 5：记忆与运营后台

- 接入用户授权的长期记忆、来源、TTL、删除传播和向量检索。
- 建立赛事与作品的导入、校对、预览、发布和撤回流程。
- 加入模型调用预算、审计日志和内容版本回滚。
- 验收：运营不改代码即可发布一届赛事；删除记忆后派生摘要和检索结果均失效。

## 阶段 6：小范围试运行

- 先开放一个主镇片区、一个展馆和少量 AI 角色。
- 进行 10 人体验测试、20 人房间压测和 60 分钟稳定性测试。
- 根据入馆、作品阅读、收藏、社交完成和 AI 费用数据决定下一轮范围。

当前决策：先完成阶段 1，再开始阶段 2。暂不把未核对的赛事结果、未授权人物资料或未完成模型包装成正式功能。

## 阶段 4：服务端权威世界与真人联机（2026-09-21 执行）

目标（对应 PRD W02 / C03 / A03 / A04 / A07，G2 出口）：两个浏览器账号在同一个房间里看到一致的公开位置，可以邀请、一对一聊天、离开；私聊不进入世界快照；断线可恢复身份与位置；同账号多开时后进入的会话明确接管。先做自包含的双用户最小验证，AI Town 接入在本阶段之后。

- 身份：本地演示身份（localStorage 稳定匿名 userId + 名帖昵称与衣带色）；界面明示这不是生产鉴权。
- 验收：`tests/world-server.test.mjs` 覆盖权威校验、私聊隐私、第三方不可读、接管、容量、幂等、断线恢复；`scripts/smoke-multiplayer.mjs` 用两个浏览器上下文完成"双账号位置一致 → 邀请 → 聊天 → 第三方只看到交谈中 → 离开"。

## 阶段 6：联机 AI 模型对话与持久预算（2026-09-21 执行）

目标（对应 PRD C02 / 15.3 / 18.1）：联机世界里与 AI 侠客的私聊可切换真实模型；预算基础保护随首次模型接入一起落地——持久账本按 requestId 去重、并发先预留后结算、每日预算达到 80% 降低后台 AI 活动、达到 100% 暂停新模型调用（看展与真人聊天不受影响），服务重启不清空费用。未配置模型或调用失败时明确回退到本地资料检索并如实标注。

- `server/budget.mjs`：持久账本 `data/usage-ledger.json`（requestId、model、tokens、cost、status、时间）；`reserve/settle` 并发预留与结算；`gate()` 返回 ok/warn/stop。
- `server/agent-brain.mjs`：统一的 AI 回复生成——人设 + 原子公社价值观 + 已发布作品结构化资料 + 角色亲身观感（observations）作为不可信资料注入；模型不可用或超预算时回退 `demoReply` 并标注模式。
- `server/world.mjs`：联机 AI 聊天携带会话历史（内存中最近 8 条）走大脑；超额时回复诚实提示，不锁定会话。

- 验收：budget 单测覆盖去重、80%/100% 阈值、重启持久化、并发预留；brain 单测以 mock fetch 覆盖模型路径与回退路径；全量 e2m/e2e 不回归。

## 阶段 7：登录与服务端验证身份（2026-09-22 执行）

目标（对应 PRD W02 / 4.1 / 4.2 / A03）：联机世界不再信任客户端传入的身份——hello 必须携带服务端会话令牌，角色 ID 由服务端从会话解析（禁止冒充他人接管）；本地演示身份替换为"侠客名帖"账号体系（注册/登录/改名帖/退出），密码 scrypt 加盐存储，会话持久化。

- `server/accounts.mjs`：账号与会话存储（`data/accounts.json`），register/login/logout/verify/updateProfile；名称 1—20 字、密码至少 6 位；会话 30 天。
- `/api/auth`：register / login / logout / me / profile 五个只读或写入接口。
